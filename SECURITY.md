# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately via GitHub Security Advisories or email the maintainers directly.

Please include:
- Description of the issue
- Steps to reproduce
- Potential impact
- Suggested fix (if available)

## Response Timeline

- Acknowledgment: within 48 hours
- Updates: regular progress updates as we investigate

## Disclosure

We follow responsible disclosure and will coordinate with you before publicly disclosing any issues.
